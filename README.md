Python（Flask）で作成した、
ニュース・天気・為替レートをまとめて表示する Web ダッシュボードです。

スクレイピング（BeautifulSoup）と API（Alpha Vantage）を組み合わせて、
複数のデータソースを統合する構成を学習目的で実装しました。


使用技術
・Python 3.x
・Flask
・BeautifulSoup4（ニュース・天気のスクレイピング）
・requests
・Alpha Vantage API（為替レート取得）
・HTML / Jinja2
・copilot


実行方法
pip install -r requirements.txt
python app.py


工夫した点
・スクレイピングとAPIを使い分けて実装
・複数データソースを統合したダッシュボード構成
・辞書リストでデータを整形し、jinja2で表示
・実務でよくある「複数機能の統合」を意識した構成


AIと自分の役割
本プロジェクトはAIを活用して設計方針やスクレイピング対象の選定を相談しつつ、基本構造をAIで作成。
実装部分（天気情報のスクレイピングと解析、API解析とレート取得、データ引き渡し、HTMLの構造を改良）はすべて自分で行いました。


今後の拡張案

スクレイピング、APIの対象サイト
・ニュース：yahooニュース
・天気：yahoo天気
・為替レート：Alpha Vantage API（無料枠を使用）


法律・規約の観点で気を付けたこと
・ニュース本文、画像などは取得・表示していません（著作権対策）
・スクレイピングは対象サイトの利用規約を確認しました
・APIは公式の無料枠を使用し、規約に従って利用しました
・過度なアクセスは行わない設計
